Text with Images lets you **attach a text caption or body alongside an image** when composing messages in blogs, forums, and private groups.

---

## Overview

Previously, images and text were sent as separate messages. Text with Images combines them into a single message, keeping context together.

This works across all group types:
- **Blogs** — write a post with inline images and text.
- **Forums** — attach images to a forum message with a caption.
- **Private groups** — send an image with a text description in a single message.

---

## How it works

1. Open a conversation, forum, or blog compose view.
2. Attach an **image** using the attachment button.
3. A **text field** appears alongside the image preview.
4. Write your caption or message text.
5. Send — the image and text are delivered together as a single message.

The recipient sees the image with the text displayed alongside it, keeping the message self-contained.

---

## Image preview with caption

When composing, the image preview appears with the text field visible below or beside it (depending on the view). This lets you review both the image and your text before sending.

Recipients see the image rendered with the caption text directly attached, rather than as separate messages in the conversation.
